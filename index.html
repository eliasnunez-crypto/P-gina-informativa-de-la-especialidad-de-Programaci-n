¿De qué trata esta especialidad?

La especialidad de Programación enseña a diseñar y desarrollar páginas web, aplicaciones y sistemas informáticos. También permite aprender diferentes lenguajes de programación y resolver problemas mediante la tecnología.

Habilidades que se aprenden

Desarrollo web

Crear páginas utilizando HTML y CSS.

Programación

Escribir código para crear soluciones digitales.

Bases de datos

Guardar, organizar y consultar información con SQL.

Resolución de problemas

Buscar soluciones utilizando el pensamiento lógico.

Ejemplos de proyectos

Páginas web

Diseñar sitios web para personas o empresas.

Sistema de inventario

Crear un sistema para registrar productos y cantidades.

Aplicaciones

Desarrollar aplicaciones que ayuden en distintas tareas.
